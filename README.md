### Ryan Speakman

Senior software engineer in Huntsville, AL. About 7 years of Python and TypeScript. Fully remote since 2019.

**I built [Agent Hub](https://github.com/Speakman-ai/agent-hub)**, a self-hosted platform for running AI coding agents (Claude Code, Codex, Cursor, Grok) across a team. A small company runs it in production.

- **Dispatch:** agents pick up cards from a kanban board, do the work in their own git worktree, and hand back a change.
- **Finalize gate:** every agent change is rebased, reviewed by a separate agent, and tested on isolated runners before a PR opens.
- **Context:** agents search the project wiki and source code before they work, with line-cited code results.
